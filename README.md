# VARify Bot
Welcome to my VARify Bot repository. This repo contains my VARify Bot solution built with Copilot Studio.

## Solution Description
VARify Bot is a custom Copilot Studio agent that integrates with a third-party API to provide information on football teams and results. The agent also stores the users favourite football team to provide a personalised experience.

## Solution Components
- **Copilot Studio**: Custom agent that allows user interaction usiNg natural language.
- **Custom Connector**: Calls a third party API to provide football team and result information.
- **Dataverse**: Table to store user favourite team.
- **Power Automate**: Cloud flows to set and fetch user favourite team.

  ## Key Features
- Automatically checks for your favourite team at the start of a conversation
- Lets you set your favourite team—and remembers it for future chats
- Provides team info and fixture updates on request
